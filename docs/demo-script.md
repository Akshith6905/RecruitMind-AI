# Live demo script (3–5 minutes)

1. Open the workspace and show the Hindsight connection state. Explain that decisions are stored in a configured persistent memory bank.
2. Create the demo AI / ML Engineer role with required Python, Machine Learning, FastAPI, and SQL.
3. Upload a consented, synthetic PDF or DOCX resume. Point out extracted profile fields and the evidence-based skills comparison.
4. Evaluate and open Memory Impact. Show the actual memories returned by Hindsight, or explain that memory is not configured if no Hindsight service is connected. Do not fabricate a before/after or imply memory changed the numeric score.
5. Enter a specific, job-related rationale and choose shortlist/maybe/pass. Explain that the feedback is retained to Hindsight for future recall.
6. Upload a second synthetic candidate for the same role and show any recalled memories in its evaluation context.

For a clean judge demo, configure and verify the Hindsight bank before the session and use synthetic candidate data. The current baseline score is a transparent skill match, not an LLM output.
